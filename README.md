# Angular SWAPI Data Grid

A single-page Angular application that displays Star Wars data from the SWAPI API in a responsive and interactive data grid.

The goal of this project is to build a clean front-end experience with smooth scrolling, editable cells, responsive table behavior, and scalable component architecture.

## Features

- Angular + TypeScript application
- SWAPI integration
- Infinite scrolling with paginated data loading
- Responsive data grid
- Column resizing
- Client-side editable cells
- Search and filtering
- Cached page requests
- Error handling and retry support

## Tech Stack

- Angular
- TypeScript
- Tailwind CSS
